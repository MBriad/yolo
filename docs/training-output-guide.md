# YOLO 训练输出文件指南

训练完成后 `runs/detect/<name>/` 下会生成一批文件。本文档用人话解释每个文件的含义和怎么看。

---

## 核心概念（理解这些就够了）

### Train vs Val — 为什么要有两份数据

```
Train（训练集）= 练习题   → 模型反复看、反复练
Val（验证集）  = 考试卷   → 模型从未见过，只用来检验
```

模型在 train 上"学习"（更新参数），在 val 上"考试"（只看不动参数）。**如果练习题越做越好，考试分反而下降，说明在死记硬背——这就是过拟合。**

### Loss — 错误率

一个数字，表示"模型有多错"。**越低越好。**

| 指标 | 含义 |
|------|------|
| `box_loss` | 框画得有多歪（位置误差）|
| `cls_loss` | 类别认错的概率（单类别项目不重要）|
| `dfl_loss` | 框的精细度误差 |

### Precision & Recall — 跷跷板

| 指标 | 人话 | 公式 |
|------|------|------|
| **Precision（精确率）** | 我说是人的框里，多少真的是人？ | 宁可不说，不说错 |
| **Recall（召回率）** | 真的人里面，我找到了几个？ | 宁可说错，不漏掉 |

这两者是跷跷板——提高一个，另一个就降。调整置信度阈值可以在这两者间取舍。

### mAP — 最终分数

```
mAP = Precision × Recall 曲线下的面积
```

一个数字同时衡量"找得准"和"找得全"。

| 指标 | 含义 | 判断标准 |
|------|------|----------|
| **mAP50** | 框和真实位置重叠 > 50% 就算对（宽松）| 主要看这个 |
| **mAP50-95** | 从 50% 到 95% 重叠取平均（严格）| 偏低正常 |

### 过拟合（Overfitting）

```
train loss ↘ 一直降（练习题越做越熟）
val loss   ↗ 反而升（考试分变差）
    → 两条线分叉 = 模型在背答案，别练了
```

## 文件逐个说明

### 1. `results.png` — 最重要的仪表盘

训练全过程的指标变化曲线，分三排：

**第一排：Loss 曲线（4 张小图）**

| 图 | 怎么看 | 决策 |
|----|--------|------|
| `train/box_loss` | 应该持续下降 | 正常 |
| `val/box_loss` | 先降后升 = 过拟合 | 该停了 |
| `train/cls_loss` | 持续下降 | 参考价值不大 |
| `val/cls_loss` | 先降后升 = 过拟合 | 同上 |

**使用方式：** 看到 val loss 和 train loss 分叉的那一刻，就是"再练下去没意义"的信号。应该在那个点停下来，取那个 epoch 的模型权重。

**第二排：评估指标（4 张小图）**

| 图 | 怎么看 | 决策 |
|----|--------|------|
| `metrics/mAP50(B)` | 越高越好 | **最高点 = 最佳 epoch** |
| `metrics/mAP50-95(B)` | 越高越好 | 和 mAP50 一起看 |
| `metrics/precision(B)` | 越高越好 | 次要指标 |
| `metrics/recall(B)` | 越高越好 | 次要指标 |

**使用方式：** 找到 mAP50 最高峰对应的 epoch，取那个时刻的模型（`weights/best.pt` 默认就是 mAP 最高的那个）。

**第三排：学习率曲线（2 张小图）**

展示了学习率随训练进程的变化。**不需要关注**，除非你在手动调学习率。

---

### 2. `results.csv` — 原始数据

每行一个 epoch，每列一个指标。用 Excel 或 IDE 打开，可以自己画图或找到精确的数值。

**使用方式：** 按 mAP50 列排序 → 找到最高值对应的 epoch → 确认该 epoch 的 val loss 没有暴涨。

---

### 3. `confusion_matrix.png` — 搞混了什么

行 = 真实类别，列 = 模型预测。

```
             预测:背景  预测:person
真值:背景      ✓         误检（没人的地方画了框）
真值:person   漏检（有人没画框）  ✓
```

理想状态：对角线亮（正确），其他位置暗（错误少）。

---

### 4. `confusion_matrix_normalized.png` — 同上（百分比版）

和上面一样，但数字换成百分比。更直观但信息量相同。

---

### 5. `BoxPR_curve.png` — Precision-Recall 跷跷板图

横轴 Recall，纵轴 Precision。显示所有置信度阈值下的 P-R 组合。

**曲线下面积 = mAP。** 曲线越靠近右上角（P=1, R=1），模型越好。

---

### 6. `BoxP_curve.png` — Precision 随置信度的变化

横轴置信度阈值，纵轴 Precision。

阈值 ↑ → 只保留高置信度框 → Precision ↑（宁可漏掉也不瞎画）

---

### 7. `BoxR_curve.png` — Recall 随置信度的变化

横轴置信度阈值，纵轴 Recall。

阈值 ↓ → 保留更多框 → Recall ↑（宁可瞎画也不漏掉）

---

### 8. `BoxF1_curve.png` — F1 分数随置信度的变化

F1 = Precision 和 Recall 的调和平均。**最高点对应的置信度是最佳阈值。**

---

### 9. `labels.jpg` — 你的数据集长什么样

三张小图：
- **左上：** 每张图里有多少个标注框（你的数据每张图平均 3-5 个人）
- **右上：** 所有标注框在图片上的位置热力图（红 = 框集中，蓝 = 框稀疏）
- **下方：** 框的宽高分布

**使用方式：** 如果位置热力图全集中在图片中间，说明数据分布不均，模型可能偏向在中间找东西。如果框尺寸分布很窄，说明缺乏尺度多样性。

---

### 10. `train_batch0.jpg` / `train_batch1.jpg` / `train_batch2.jpg`

训练最开始几个 batch 的图片（经过数据增强后）。

**这就是模型真正"吃"进去的数据。** 你会看到图片被翻转、颜色变了、几张图拼成一张（mosaic 增强）。

---

### 11. `train_batch280.jpg` / `train_batch281.jpg` / `train_batch282.jpg`

训练最后几个 batch 的图片（同样经过数据增强）。

用来对比训练初期和后期的增强效果有没有变化。

---

### 12. `val_batch0_pred.jpg` — 模型画的答卷

验证集图片上模型的预测结果。红色框 = 模型认为这里有人。

**肉眼判断：**
- 框的位置对了吗？
- 有漏的吗？
- 有瞎画的吗？

---

### 13. `val_batch0_labels.jpg` — 标准答案

同一批验证集图片上的人工标注（正确答案）。

**和上面那张对比着看：**
- 标准答案有、模型没画 → 漏检（Recall 低的原因）
- 标准答案没有、模型画了 → 误检（Precision 低的原因）

## 实际流程：怎么看这些图

```
1. 打开 results.png → 看 mAP50 曲线最高点在哪
   ↓
2. 打开 results.csv → 确认最高 mAP50 对应的 epoch
   ↓
3. 看 val/box_loss 和 train/box_loss 有没有分叉
   → 分叉了 = 过拟合，应该在分叉点的 epoch 停下来
   ↓
4. 打开 val_batch0_pred.jpg → 肉眼看看检测效果
   → 框歪不歪？漏没漏？瞎画没？
   ↓
5. 打开 val_batch0_labels.jpg → 和上面对比
   → 哪些是漏检，哪些是误检
   ↓
6. (可选) 打开 train_batch0.jpg → 看看数据增强长什么样
```

**如果过拟合了：**
- 增加数据量（最有效）
- 减少 epochs（早点停）
- 增加数据增强强度

**如果 mAP 很低（< 0.3）：**
- 数据量太少（你目前 49 张，确实少）
- 标注质量差（框没画准）
- 数据集太难（目标太小、遮挡严重）
